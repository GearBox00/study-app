# まなびカード（学習アプリ サンプル）

さいたま市・佐藤様の学習アプリ案件向けのデモです。
**第1段階（数週間・低予算で実現できる範囲）が実際に動く形**で入っています。

## 動かし方

このフォルダをそのままWebサーバーに置くだけです。ビルド作業はありません。
手元で見る場合は、フォルダ内で次を実行してブラウザで `http://localhost:8770` を開きます。

```bash
python -m http.server 8770
```

※ `file://` で直接開くとPWA機能が動かないため、必ずサーバー経由で開いてください。

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み（全画面が1ファイルに入っています） |
| `css/style.css` | 見た目 |
| `js/data.js` | **問題データ**。CSVから取り込んだデータもこの形になります |
| `js/app.js` | 学習ロジック（復習判定・タイマー・発音・記録） |
| `sw.js` / `manifest.json` | PWA（ホーム画面に追加・オフライン起動） |

## 実装済み（＝第1段階の提案範囲）

- フラッシュカード（タップでめくる）
- 4択テスト（制限時間10秒・残り3秒で赤く点滅）
- **4択の自動生成** … 同じセット内の他の答えを誤答に使うので、問題データは「問題・答え・解説」だけあれば足ります
- 発音（**ブラウザ標準の音声合成**を利用。音声ファイルの用意も利用料も不要）
- 正解表示と同時の解説表示、何度でも押せる発音ボタン
- 間違えた問題の自動再出題＋**復習コーナー**（正解できたら卒業）
- 習得数・のべ解答数の記録（連続2回正解で「習得」）
- ニックネーム・マイページ（科目別の習得数と復習待ち数）
- CSV貼り付けによる問題セット追加
- 科目・レベル・セット（1セット50問想定、デモは10問）の階層管理
- スマホ／パソコン両対応、PWA（ホーム画面に追加・オフライン起動）

## あえて入れていないもの（＝第2段階の候補）

| 項目 | 理由 |
| --- | --- |
| メールアドレス登録・サーバー保存 | デモは端末内保存のみ。子どもの個人情報を預かる範囲を先に決める必要があるため |
| オフライン中の解答をサーバーへ同期 | 「オフラインで起動・学習できる」ところまでは実装済み。同期は競合処理の設計が別途必要 |
| 同時数千人の負荷試験 | 実現方法はあるが、DB設計・負荷試験・利用料監視で工数が別枠になる |
| タイピングテスト | 出題形式の追加自体は軽いが、採点ルール（大文字小文字・スペルミス許容）の決めごとが必要 |
| 管理者用の問題管理画面 | CSV貼り付けで代替できるため、まずは運用してから判断 |
| 学校・クラス単位の管理、学習分析 | 実証実験の結果を見てから設計するのが安全 |

## 設計上の工夫（コストを下げている部分）

1. **音声を合成音声にした** … 7,000語ぶんの音声ファイル制作・保管・配信が丸ごと不要になります。
2. **誤答を自動生成にした** … 問題作成時に選択肢を4つ作る手間がなくなり、AIで作った「単語・意味・解説」のCSVをそのまま使えます。
3. **保存処理を1か所（`Store`）にまとめた** … 将来アカウント機能を付けるときは、この部分をサーバー通信に差し替えるだけで済みます。
4. **ビルド不要の構成にした** … 保守できる人の範囲が広がり、公開も安価なサーバーで済みます。

## 更新時の注意

`sw.js` がファイルをキャッシュするため、内容を更新したときは `sw.js` の
`const CACHE = 'manabi-card-v1';` の番号を上げてください（例: `-v2`）。
上げないと、利用者の端末で古い画面が表示され続けます。

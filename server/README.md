# サーバー側（第2段階）

学習の記録をサーバーに預け、生徒・先生・運営者で見え方を分けるための仕組みです。
Xサーバーの標準機能（PHP・MySQL）だけで動きます。追加の契約は要りません。

## 中身

| ファイル | 役割 |
| --- | --- |
| `schema.sql` | データベースの設計 |
| `setup.php` | 表を作り、見本の利用者を入れる（コマンドから実行） |
| `config.sample.php` | 接続の設定の見本。**コピーして `config.php` を作ります** |
| `lib.php` | 共通処理。**権限の判定はここに集約** |
| `api/login.php` | ログイン |
| `api/logout.php` | ログアウト |
| `api/whoami.php` | いま誰か（役割の判定に使う） |
| `api/record.php` | 学習の記録の受け渡し |
| `api/students.php` | 生徒の名簿と、在籍状態の変更 |

## いちばん大事なこと

画面側（`js/auth.js`）の出し分けは、**うっかり触らせないための目隠し**です。
端末の中を書きかえれば通せてしまいます。

ですから、**同じ判定を `lib.php` にも書いています**。
`lib.php` の `$PERMISSIONS` と `js/auth.js` の `PERMISSIONS` は同じ中身でなければならず、
`検証/t_server.py` が毎回突き合わせています。片方だけ直すと検証が落ちます。

## 手元（XAMPP）で動かす

```
# 1. データベースを起動（XAMPPコントロールパネルの MySQL でも可）
C:\xampp\mysql\bin\mysqld.exe --standalone

# 2. 設定を作る
copy server\config.sample.php server\config.php

# 3. 表と見本の利用者を用意する
C:\xampp\php\php.exe server\setup.php --sample

# 4. アプリごと動かす
C:\xampp\php\php.exe -S 127.0.0.1:8899 -t .

# 5. js/config.js を書きかえる
const SERVER_BASE = 'server/api/';
```

見本のログイン（**手元で試すためだけのものです。本番では必ず作り直してください**）

## Xサーバーへ移すとき

1. 管理画面でデータベースを作る（名前・利用者・パスワードを控える）
2. `config.php` をその値に書きかえる
3. `server/` フォルダをアップロードする
4. SSH で `php server/setup.php` を一度だけ実行する（`--sample` は付けない）
5. 運営者のアカウントを1件だけ手で作る
6. `js/config.js` の `SERVER_BASE` を書きかえる
7. `sw.js` の `CACHE` の版番号を上げる

**半日から1日**の見込みです。

## 気をつけること

- `config.php` は**公開リポジトリに置かないでください**（`.gitignore` に入れてあります）
- パスワードは `password_hash()` で保存し、**生のまま持ちません**
- サーバーとのやりとりは、サービスワーカーが**絶対に保存しない**設定にしてあります
  （保存すると、ログイン前の「あなたは生徒です」が残り続けます。2026-08-11に実際に起きました）
- `audit_log` に「誰がいつ何をしたか」が残ります。個人情報を扱う以上、跡は必要です
- 学習の記録は1人4MBまでにしています。上限が無いと、1人で保存領域を使い切れてしまいます

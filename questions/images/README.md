# 画像置き場

問題に図や写真を付けるときは、**このフォルダに画像を置いて**、
CSVの「画像」欄に**ファイル名だけ**を書きます。

## 手順

1. 画像をこのフォルダに入れる（例：`chizu-01.jpg`）
2. CSVの「画像」欄に `chizu-01.jpg` と書く
3. アプリを更新（配信）する

CSVの列は左から次の11個です。「画像」は11番目（いちばん右）です。

```
問題, 答え, 解説, 例文, 制限時間, 読み, 誤答1, 誤答2, 誤答3, セット, 画像
```

画像を使わない問題は、欄を空にしておいてください。
これまでの10列のCSVも、そのまま取り込めます。

## 画像のきまり

| | |
| --- | --- |
| 形式 | JPG または PNG（図やグラフはPNG、写真はJPGが向いています） |
| 大きさ | 横幅800ピクセル程度。それ以上は画面で違いが分かりません |
| 容量 | **1枚300KBまで**。写真をそのまま入れると5MBほどあり、タブレットで目に見えて遅くなります |
| ファイル名 | 半角の英数字とハイフンをおすすめします（例：`chizu-01.jpg`） |

`https://` で始まるアドレスを書くこともできますが、
**通信がないと表示されず**、他人のサイトの画像は著作権の問題があります。
このフォルダに置く方法をおすすめします。

## 画像の著作権について

**使えないもの**

- 市販の教科書・問題集・参考書のスキャン
- インターネット検索で出てきた画像
- Googleマップの画面を撮ったもの

**使えるもの**

- 自分で撮影した写真、自分で作図した図
- 国土地理院の地図（「出典：国土地理院」の表示が必要）
- 政府・自治体の公開資料（出典表示が必要。個別に利用規約の確認を）
- CC0・パブリックドメインの素材（配布元の記録を残してください）

人が写った写真は、著作権とは別に**肖像権**の問題があります。
生徒や保護者が写った写真を使う場合は、本人（未成年なら保護者）の同意が必要です。

判断に迷う画像は、そのつどご相談ください。

## 注意

画像を足したり差し替えたりしたら、`sw.js` の `CACHE` の版番号を上げてください。
上げないと、すでにアプリを開いたことのある端末では古い画像が出続けます。

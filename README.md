# まなびカード（学習アプリ サンプル）

さいたま市・佐藤様の学習アプリ案件向けのデモです。
**第1段階（数週間・低予算で実現できる範囲）が実際に動く形**で入っています。

公開先： https://gearbox00.github.io/study-app/

## 動かし方

このフォルダをそのままWebサーバーに置くだけです。ビルド作業はありません。
手元で見る場合は、フォルダ内で次を実行してブラウザで `http://localhost:8770` を開きます。

```bash
python -m http.server 8770
```

※ `file://` で直接開くとPWA機能が動かないため、必ずサーバー経由で開いてください。

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み（全画面が1ファイルに入っています） |
| `css/style.css` | 見た目 |
| `js/data.js` | **内蔵の問題データ**（問題・答え・解説・例文・読み） |
| `questions/` | **外部の問題ファイル**。`index.json` に書いた CSV を起動時に読み込みます |
| `js/app.js` | 学習ロジック（復習判定・タイマー・発音・記録） |
| `js/stamp.js` | 出席スタンプカード（QR読み取り・入退室・勉強時間） |
| `js/tools.js` | 記録の持ち運び・紙のテスト印刷・問題の編集削除・CSV取り込み |
| `js/boot.js` | 起動処理（他のファイルを読み終えてから動きます） |
| `vendor/` | 同梱した外部ライブラリ（QRの読み取りと生成）。詳細は `vendor/README.md` |
| `sw.js` / `manifest.json` | PWA（ホーム画面に追加・オフライン起動） |

## 実装済み（＝第1段階の提案範囲）

- フラッシュカード（タップでめくる）
- 4択テスト（制限時間10秒・残り3秒で赤く点滅）
- **4択の自動生成** … 同じセット内の他の答えを誤答に使うので、問題データは「問題・答え・解説」だけあれば足ります
- 発音（**ブラウザ標準の音声合成**を利用。音声ファイルの用意も利用料も不要）
- 正解表示と同時の解説表示、何度でも押せる発音ボタン
- 間違えた問題の自動再出題＋**復習コーナー**（正解できたら卒業）
- 習得数・のべ解答数の記録（連続2回正解で「習得」）
- ニックネーム・マイページ（科目別の習得数と復習待ち数）
- CSV貼り付けによる問題セット追加
- **タイピングテスト**（意味を見て英単語のつづりを入力。1文字ずつ色分け表示、制限時間15秒、大文字小文字は区別しない）
  - つづりが半角英字の問題のときだけモード選択に出ます（漢字・日本史では自動的に非表示）
- **リスニング**（発音だけを聴いて意味を4択で答える）
- **カードの仕分け**（「知っている／知らない」。左右へのドラッグでも仕分け可能）
- **出題の向き切り替え**（問題→答え／答え→問題）
- **スキップ**（記録を増やさずに問題を後ろへ回す）
- **赤シート**（カードの答えを隠し、タップで表示）
- **音声の速さ**（ゆっくり／ふつう／はやい）
- **間隔反復の復習**（正解するたび 1日後→3日後→1週間後→2週間後 と間隔が延び、間違えるとすぐ復習対象に戻る）
- **連続学習日数（ストリーク）** と **1日の目標＋達成メーター**
- **平均解答時間の記録**
- **学習グラフ**（直近2週間の日別学習量。目標達成日は緑）
- **バッジ**（全10種。解答数・習得数・継続日数・全問正解など）
- **苦手な問題リスト**（間違えた回数順。そこだけまとめてテストできる）
- **単語検索**（問題・意味・読み・解説・例文のどれからでも検索）
- **マイ単語帳**（1語ずつ自分で登録）
- **例文表示**（カード・解答後・検索結果に表示）
- **出席スタンプカード**（5×5＝25マス）
  - 拠点に掲示したQRコードを読み取って、1日1つ💮スタンプを押す
  - 入室時と退室時に読み取ると、その日の勉強時間を記録する
  - 25マスたまると次のカードへ。カメラが使えない端末向けに手入力も用意
  - 拠点用のQRコードはアプリ内で作成・印刷できます（マイページ→出席スタンプ→拠点用QRコード）
- **記録の書き出し・読み込み**（USBメモリに入れて別のパソコンで続きができます）
- **紙のテストの印刷**（範囲・問題数・4択/記述・出題の向き・解答つきを選べます）
- **制限時間の設定**（作問者はCSVの5列目で問題ごとに指定、生徒は設定画面で変更。テストモードでは作問者の指定で固定）
- **問題の編集・削除**（自分で追加した問題）
- **Excelからの貼り付けに対応**（タブ区切り・引用符つきのデータを読めます）
- **問題を外部のCSVファイルから読み込む**（`questions/index.json` に登録。大量データはこの方式へ）
- 科目・レベル・セット（1セット50問想定、デモは10問）の階層管理
- スマホ／パソコン両対応、PWA（ホーム画面に追加・オフライン起動）

## あえて入れていないもの（＝第2段階の候補）

| 項目 | 理由 |
| --- | --- |
| メールアドレス登録・サーバー保存 | デモは端末内保存のみ。子どもの個人情報を預かる範囲を先に決める必要があるため |
| オフライン中の解答をサーバーへ同期 | 「オフラインで起動・学習できる」ところまでは実装済み。同期は競合処理の設計が別途必要 |
| 全国・クラス内ランキング | 他の子と競う仕組み。アカウントとサーバー集計が前提 |
| 学習リマインド通知 | 配信サーバーが必要。iPhoneは制約が多め |
| 同時数千人の負荷試験 | 実現方法はあるが、DB設計・負荷試験・利用料監視で工数が別枠になる |
| 管理者用の問題管理画面 | CSV貼り付けで代替できるため、まずは運用してから判断 |
| 学校・クラス単位の管理、学習分析 | 実証実験の結果を見てから設計するのが安全 |

## 設計上の工夫（コストを下げている部分）

1. **音声を合成音声にした** … 7,000語ぶんの音声ファイル制作・保管・配信が丸ごと不要になります。
2. **誤答を自動生成にした** … 問題作成時に選択肢を4つ作る手間がなくなり、AIで作った「単語・意味・解説」のCSVをそのまま使えます。
3. **保存処理を1か所（`Store`）にまとめた** … 将来アカウント機能を付けるときは、この部分をサーバー通信に差し替えるだけで済みます。
4. **ビルド不要の構成にした** … 保守できる人の範囲が広がり、公開も安価なサーバーで済みます。

## 更新時の注意

`sw.js` がファイルをキャッシュするため、内容を更新したときは `sw.js` の
`const CACHE = 'manabi-card-v1';` の番号を上げてください（例: `-v2`）。
上げないと、利用者の端末で古い画面が表示され続けます。
